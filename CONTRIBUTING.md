# Contributing

Keep the apps offline for local playback and preserve original media. Use bounded workers,
buffers and parsing; keep input/keys owned by focused controls. New formats need actual decode
evidence, not just an extension in a picker. Preserve conditional codec states and clear failures.

Run the affected format, strict lint, tests and release build. Document what was tested and what
was not, including hardware/platform conditions. Avoid unrelated formatting in shared code.
For decoder changes, update exact provenance, notices, source availability and all runtime DLLs.
